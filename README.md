# 🎯 One-Tap Headshot Sensitivity & HUD Setup Hub (2026)

A lightweight, mobile-first web hub offering competitive sensitivity presets, custom HUD positioning, and device-specific DPI calibration for mobile battle royale games.

---

## ⚡ Live Features

- **Open-Access Sensi Table:** Instant on-page values for General, Red Dot, 2x, 4x, and Fire Button configuration.
- **Pro Master Setup (PDF Pack):** Extended guide covering 2-finger, 3-finger, and 4-finger HUD diagrams, DPI adjustments, and FPS optimization.
- **Lightning-Fast Hosting:** Deployed on Cloudflare Pages using global Edge CDN caching.
- **Zero-Cost Infrastructure:** Runs completely on ₹0 budget using GitHub and Cloudflare Pages.
